# KeepCV 0.1.6

This release preserves unfinished form inputs and handles PostgreSQL disconnects
without replaying transactions.

## Form recovery

All five Job target fields retain unfinished inputs after a refused save,
navigation, reload or sign-out. Recovery also covers Profile, Record, Point,
metrics, Evidence, record links and fields, and contact forms. Saves remain
explicit; restored inputs are not submitted automatically.

Recovery follows the editor's connected-store namespace. Original conflict
tokens remain with recovered edits, and a successful older save does not clear
newer input. Acknowledgment or explicit discard clears the corresponding copy.
Recovery copies stay outside native backups and resume documents.

## PostgreSQL recovery

Idle pool disconnects no longer produce unhandled process errors or raw
diagnostics. Checked-out connections retain error handling through transaction
cleanup, refused connections are retired, and later operations can reconnect.
An interrupted transaction fails once; its callback is never replayed. A failed
rollback preserves the original disconnect error.

The API patch updates packaged database development-dependency metadata.
With Node 24 or newer, after publication:

```sh
npx --yes @keepcv/cli@0.1.6 serve
```

Open the complete URL printed by the launcher. Existing stores use the same
schema; this release adds no database migration.

## Verification

Editor tests cover refusal, remount, reload, namespace isolation, stale conflict
tokens, discard and overlapping edits. Database tests cover idle and checked-out
disconnects, rollback failure, bounded reconnection and repeated close on both
PGlite and server PostgreSQL. Isolated installed-package tests exercise editor
recovery and PostgreSQL disconnect handling through their public entries.
Release validation checks the complete package set, launcher round trips and
exact tarball integrity before publication.
