# KeepCV 0.2.3

The assistant can choose web queries, refine searches and read result links
without exact-query or per-page approval forms. Configured web access starts on;
its choice carries across chats in the connected editor session.

## Chat controls

A plus menu groups attachments, Web search, settings and input recovery. The
active Web search chip provides one-click opt-out. Selected attachments and
active task edits remain visible. Sharing, task permissions and collapsed file
limits live in a separate settings dialog, keeping the composer compact on
wide and narrow screens. Menus support keyboard navigation, Escape dismissal
and focus return. Sharing acknowledgment lasts for the connected editor session.

## Web access

Server configuration can use web: {} with its existing inference route. Defaults
select Parallel turbo search and OpenRouter fetch. Domain filters are optional.
A web-enabled turn allows agent-chosen queries and URLs; switching web access off
removes both tools. Legacy approval fields remain readable for older callers
and historical messages, but no longer constrain the assistant's web work.

The default allowance increases to eight web calls, 4000 search excerpt
characters per result and approximately 12000 fetched context tokens. Fetched
findings are no longer cut at the search excerpt size. Execution reporting,
source provenance, cancellation and owner/session authority remain enforced.
Search without citation annotations may return findings without invented links;
fetch retains its requested URL. No migration, native archive version change or
application stream event change is required. Native format remains v3.
