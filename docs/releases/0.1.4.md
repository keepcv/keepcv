# KeepCV 0.1.4

This release makes career data easier to edit and resumes easier to assemble.
The editor uses shorter labels, explains the main content types, and reveals
optional controls when needed.

## Editing and navigation

- Import a resume from Overview, including when the store already has content.
- Create and edit record summaries, with retry after a failed save.
- Expand alternate wordings, formatting, metrics, evidence and custom fields
  as needed. Existing values remain visible and drafts retain recovery controls.
- Navigate from a point to its parent record and distinguish repeated titles
  using the organisation and dates.
- See which resumes use a summary's default wording. Hidden entries count;
  removed entries and archived content do not.
- Use dropdowns that follow the app theme, including native keyboard controls.

## Resumes and templates

Choose a template while creating a resume, or start from a template's page.
Failed resume and design creation retains entered values for retry. Nested
records and points show their identity and selection controls first, with
wording choices and other details available on demand.

Content, Job target, Preview and export, and History name the main steps.
Common exports stay visible; other formats, checks and layout controls expand
when needed. A short content guide explains records, points, wordings and
resumes, including how removing content from a resume keeps it in the store.

## Reusable editor

`Editor` accepts optional `dataPage` guidance for storage, backup and restore.
Consumers can omit terminal instructions while retaining browser backup and
restore. See the [editor guide](../../packages/editor/README.md).

## Versions and running

| Package | Version |
|---|---|
| `@keepcv/cli`, `@keepcv/api`, `@keepcv/core`, `@keepcv/interop` | 0.1.4 |
| `@keepcv/db` | 0.2.1 |
| `@keepcv/editor` | 0.3.0 |
| `@keepcv/schema`, `@keepcv/templates`, `@keepcv/render`, `@keepcv/ats-lint` | 0.1.3, unchanged |

With Node 24 or newer, after publication:

```sh
npx --yes @keepcv/cli@0.1.4 serve
```

Open the complete URL printed by the launcher. Existing stores use the same
schema; this release adds no database migration. Native backups retain archived
content, drafts and history. Private evidence remains excluded from resumes.

## Verification

Checks cover summary creation and retry, retained form values after failures,
draft recovery, nesting, usage selectors and keyboard controls. Browser review
uses a populated store across desktop and mobile layouts in both themes.
Installed-package checks exercise the editor consumer and launcher writes,
exports, backup and restore. The release workflow tests both database drivers
and verifies the exact tarballs before publication.
