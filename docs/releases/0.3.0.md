# KeepCV 0.3.0

Set up KeepCV interactively with `keepcv setup`, or configure the launcher with
`KEEPCV_*` environment variables. Explicit flags override environment values,
then saved settings, then defaults. Setup offers server, sign-in and optional
OpenRouter chat sections with masked credentials and cancellation before save.

The Docker image runs the packaged application as a non-root user, retains data
under `/data`, and starts with `serve`. The Compose file forwards settings from
its environment or a local `.env`; copy `.env.example` to get started. Container
publishing is integrated with release validation and pushes the tested image to
`ghcr.io/keepcv/keepcv:0.3.0` and `:latest`. Published images target Linux amd64.

Long resume import reviews stay inside the content scroll area. Hidden import,
asset-upload and assistant controls no longer extend the outer editor. Dialogs
fit the dynamic viewport and contain scrolling; import and asset controls show
keyboard focus.

Existing stores and native archive format v3 are unchanged. No migration is
needed. Launcher configuration and password credentials remain outside native
career-data exports; retain the data volume and protect those operational files.
Unchanged library versions reuse their integrity-verified registry tarballs.

```sh
npx --yes @keepcv/cli@0.3.0 setup
npx --yes @keepcv/cli@0.3.0 serve
```
