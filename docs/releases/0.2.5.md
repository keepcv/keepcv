# KeepCV 0.2.5

The launcher serves .mjs module workers with text/javascript rather than
application/octet-stream. This fixes standalone PDF import under nosniff when
using the packaged PDF worker. Same-origin CSP and nosniff remain unchanged.

Release smoke tests now fetch every installed worker over HTTP and verify its
JavaScript MIME type, nosniff header and exact bytes. The regression reproduced
the incorrect media type before the mapping was fixed.

The editor host ports, first-send consent and format capabilities are unchanged
from 0.2.4. Hosted consumers already serving workers as JavaScript retain the
same editor/library versions. Use launcher 0.2.5 for standalone PDF import.

No migration, native archive, permissions or event vocabulary changes are added
by this patch. Native format remains v3. Existing package versions and tags are
unchanged; the release reuses their verified original registry bytes.

```sh
npx --yes @keepcv/cli@0.2.5 serve --agent-config agent.json
```

See [host verification](../testing/editor-host.md) and the editor README for
consumer setup and the sharing, format, host-action and recovery contracts.
