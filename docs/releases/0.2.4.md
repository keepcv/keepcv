# KeepCV 0.2.4

A valid first send now opens sharing consent with the current server disclosure,
selected-input scope and effective Web search choice. Allow and send submits the
unchanged intended request once; Not now/Escape retains text, files, originals
and page context. Acceptance lasts for the connected editor session. Capability
refresh detects changed processing scope before sending; remount or an owner
connection change starts fresh. Revoking future sharing remains separate from Stop.

## Editor host composition

Optional sizing="container" fills a finite parent below host chrome and notices;
viewport remains the default. hostActions provides labeled HTTP(S) links or
callbacks in System navigation, including collapsed and mobile states.
recoveryActions receives safe message, Problem and server Retry-After context
across root, save and assistant failures. Presentation updates preserve the router,
cache and composer; they never authorize or automatically replay work.

Generation media types are advertised by the server, derived from configured
model routes and optionally narrowed by createAgent/createApi policy. Chooser,
drop checks, sharing and settings reflect the effective set. Legacy/custom
adapters without metadata default to text-only generation; advertise qualified
image/PDF types explicitly. Original storage/downloads, history, native backup,
ordinary editing and free export remain independent of generation and sharing.

## Browser assets

The editor exports favicon.svg with system light/dark behavior and MIT licensing.
PDF import initializes a packaged PDF.js module worker automatically. Parser and
worker are pinned to 6.5.438; no direct PDF.js bootstrap is needed in consumers.
The worker is emitted separately, avoiding data/blob worker exceptions to CSP.
DOCX retains its existing bundled worker. Installed browser checks reached import
review for synthetic PDF/DOCX under same-origin CSP and a relocated asset prefix.

Serve workers as JavaScript and permit same-origin script-src/worker-src. No
broader worker policy or CDN fallback is required. See the editor README for
public entries and [host verification](../testing/editor-host.md) for the fixture,
keyboard, finite-height, consent, failure and owner checks.

No migrations, native archive version changes or new permission grants are added.
Native format stays v3. Application event names are unchanged; error events gain
optional safe problem and retryAfter metadata. Older text-only events and saved
history remain readable without inventing missing metadata or resuming work.

Requires Node 24 or newer. After publication:

```sh
npx --yes @keepcv/cli@0.2.4 serve --agent-config agent.json
```

Mounted consumers should update to the compatible set, import compiled CSS,
remove direct PDF.js worker initialization, and supply a fresh cache/recovery
namespace with unmount and server authority revocation when changing owners.
