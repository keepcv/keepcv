# KeepCV 0.2.0

This release adds conversational career-data assistance and configurable editor,
API and runtime integration. Ordinary editing and export work without a model.

## Assistance and original files

Chat is the default dashboard; a contextual panel works with major pages. Typed
proposals show reviewable changes and save receipts atomically with edits.
Archive, restore and merges retain exact review. Bounded task permissions permit
ordinary edits to named resources. Private Evidence and permanent erasure have no
model tool.

Startup configuration chooses OpenRouter routes, allowed providers, failover,
image/PDF support and native hosted research. Users cannot select providers or
models. Hosted research requires a qualified native-only workspace policy and the
exact public query approved through the user control. Original PDF, image and
UTF-8 files remain in the owned store and native backups.

## Embedding and recovery

Consumers can choose Overview as home and hide generation while keeping saved
conversations and original downloads. Server authorization revalidates task reads,
proposals and writes; presentation options do not authorize requests. Effective
file and turn limits are reported to the editor. The built-in adapter offers
bounded usage/completion events without private content; missing counts stay
unknown. Custom models remain supported.

Process-local admission, grants and revocations have bounded retention. Review
expires after thirty minutes; each authority collection has a 128-entry ceiling.
Revocation overflow permanently retires the instance instead of forgetting revoked
scopes. Close is terminal. Replacement needs current authorization; history never
restores active authority. Stop cannot clear another process's lease: unconfirmed
local cancellation against an unexpired lease returns 409 with expiry guidance.
Cancellation does not reverse admitted external calls or committed changes.

The conversation has readable change previews, correction drafts, keyboard
submission, accessible message/status updates and responsive transcript scrolling.
Optional controls are grouped; errors and recovery remain visible.

## Data and versions

Native export uses archive v3. Older archives gain empty conversation/file
collections on import. The SQL migration adds two owned tables; no data is removed.

```sh
npx --yes @keepcv/cli@0.2.0 serve
```

The first publication of @keepcv/agent requires bootstrap mode. Configure its npm
trusted publisher after that publication, then revoke the bootstrap credential.
Live provider qualification requires operator credentials and workspace policy
verification; deterministic checks use synthetic models and files.
