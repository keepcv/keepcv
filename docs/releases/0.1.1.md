# KeepCV 0.1.1

The first complete release of KeepCV, a career data store that compiles into resumes.
Keep your career history in one place and select what belongs on each resume.
Taking something off a resume leaves it in the store.

## What is included

- A local browser app for your profile, career records, points and alternative
  phrasings, with drafts, revision history, tags and search.
- Resume composition, tag-based role profiles, two built-in designs and an
  editor for your own templates, with preview and length guidance.
- Automatic resume versions and named snapshots, with comparison and restore.
- HTML, browser-printed PDF, Word, LaTeX, Typst and JSON Resume export, plus a
  self-contained portfolio page. Format-specific losses are shown before export.
- Import review for PDF, Word, JSON Resume, Reactive Resume and RenderCV files.
- An ATS linter reporting observable document problems, without claiming
  certification against a particular applicant tracking system.
- Whole-store backup and restore, a readable backup mirror, and token,
  password or trusted-proxy authentication for a single owner.

The launcher includes the built web app. The eight `@keepcv/*` libraries are
published separately for consumers of the schema, domain logic, database, API,
templates, rendering, format adapters and linter.

## Running the release

Once published, with Node 24 or newer:

```sh
npx keepcv@0.1.1 serve
```

Open the complete URL printed by the launcher, including its token fragment.
The default data directory is `~/.keepcv`. Use `--data-dir` to choose another.

## Limits to understand

This is an early release. Keep a native backup before importing or making
large changes. Native restore requires an empty target store; importing a
resume into an existing store goes through review instead.

PDF export uses the browser's print dialog. Page-length guidance is advisory;
check the printed result. PDF and Word import infer structure where the file
does not declare it, so review the proposed records before applying them.

Portfolio export produces a file to host yourself. KeepCV does not provide
hosting, accounts, job tracking or AI writing.

## Publication recovery

This release replaces the partial 0.1.0 publication. All nine public packages
use 0.1.1, including their internal dependencies. The launcher was not published
at 0.1.0, and the pre-existing core package at that version lacked runtime files.

The workflow checks every existing registry version against the reviewed
tarballs before publishing any package and waits for registry propagation after
each successful publish.
