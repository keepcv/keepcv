# KeepCV 0.3.1

KeepCV now provides standalone SVG logos, icons and illustrations, along with
PNG sizes for common uses. Editor consumers can import those assets through
`@keepcv/editor/assets/*` and find the available sizes in the asset catalog.

The launcher serves the application icon manifest and refreshes unversioned
branding after upgrades. Existing stores require no migration.

| Package | Version |
|---|---|
| @keepcv/cli | 0.3.1 |
| @keepcv/editor | 0.10.2 |

The [three-minute walkthrough](../../videos/keepcv/showcase/keepcv-3min.mp4)
shows the KeepCV Assistant, job targeting and resume review.

```sh
npx --yes @keepcv/cli@0.3.1 serve
```
