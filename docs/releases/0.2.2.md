# KeepCV 0.2.2

The assistant can search the public web and read approved public pages through
explicitly configured engines. A Web search switch in the composer controls
whether search is available to the model for each turn.

## Search and page reads

The OpenRouter adapter supports Parallel turbo search and OpenRouter page fetch
without requiring native web tools from the selected model. Engine selection is
explicit. Public-only hosted calls carry the approved query or URL, not private
career records, attachments or conversation context. Search and fetch have
bounded call counts, results, returned context, response bytes and deadlines.
The adapter does not retry or switch engines after a web tool starts.

Reported server-tool execution is required before accepting findings. External
call usage is observed separately from model tokens. Search retains provider
citations; a fetch without citation annotations retains the requested URL with
an explicit provenance label. Sources and tool activity survive interrupted
replies, saved conversations and native recovery. Provider internal query,
redirect and DNS behavior are delegated to the configured service.

## Control from the composer

Web search starts off. Enabling it reveals a public-query field; disabling it
removes the research tool for that turn. The switch resets when changing
conversations and is unavailable when the API reports no configured search
support. Page fetching retains separate exact URL approval and disclosure.
Current owner/session authorization continues through external calls, resource
reads, proposals and accepted changes. Ordinary editing, originals, history and
export remain available without web tools or a model.

## Compatibility

The API adds webSearchAvailable capabilities and optional webSearchEnabled turns.
Legacy custom runtimes default to unavailable search. Custom AgentModel adapters
may advertise support and should honor the turn flag. Older callers omitting the
flag retain their explicit public-query approval. Native archive version stays 3
with optional page approvals, per-turn search state and source provenance. Older
readers may discard that metadata; update readers together. No migration is
required. Application stream event types are unchanged. Usage observers gain
external-tool events, so exhaustive observer switches need the new variant.
