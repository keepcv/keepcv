# KeepCV 0.2.1

This release adds the Index Drawer visual identity and a unified assistant
workspace with visible tool activity and clearer change permissions.

## Identity and conversation workspace

Shared vector branding now appears in navigation, entry screens and the favicon.
Store, selection and snapshot illustrations follow the same identity in light
and dark themes. Resume output remains career content without application branding.

Assistant and conversation history share one workspace. Searchable History keeps
the application sidebar clear. The composer stays reachable while messages scroll,
and tool names and purposes remain visible without expanding a disclosure.

Ask KeepCV opens a fresh conversation on the Assistant page with removable
source-page context. The selected conversation remains in History. Source context
carries through subsequent turns and bounded task permissions. The shortcut never
sends automatically or discards unsent composer input.

Review, task permission limits, revocation and sharing consent remain explicit.
Stopping suppresses the expected browser stream-abort exception while retaining
real refusal errors and interrupted history. Text replies support safe formatting
without interpreting model-authored HTML. Tool-step narration uses separate
paragraphs, text attachments identify their source, and Point creation guidance
avoids proposing the same phrasing set twice.

## Compatibility

Optional tool activity survives saved conversations and native archives, including
interrupted replies. Existing messages and custom model adapters remain supported.
The application event vocabulary adds tool events; consumers exhaustively handling
that vocabulary should handle the new member. No database migration is required.
Native archive version remains 3.

This release does not add web-fetch integration or change the configured research
policy. Ordinary editing and export remain available without a model.
