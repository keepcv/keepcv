# KeepCV 0.1.8

This release adds reusable visual and HTML template builders and simplifies the
resume design and export experience.

## Templates and resumes

The library separates read-only system templates from editable user templates.
Six refreshed Default designs preserve the original system ids for existing
resumes. Studio, Signal and Folio add HTML layouts; Studio and Signal target
creative work with poster and portfolio compositions.

Both builders offer explicit saving, undo/redo, scoped draft recovery, copying,
import/export and previews with sample or selected resume content. HTML authors
edit local source/partial/asset files and discover ordered sections, records,
points, fields, links, metrics and groups through the selected-data explorer.
Page defaults and per-resume fit remain separate.

Resume Design stages a template choice before Apply and retains existing fit
settings by default. PDF export stays in the header; other formats use a focused
dialog. The printer skips the initial blank iframe load.

## Safety and compatibility

HTML uses a bounded binding language without JavaScript, host APIs or external
loaders. Markup, CSS, links and bundled assets are checked, with CSP and
script-free preview/print frames. Browser rendering has cancellation and a
parent-owned deadline. Readability findings remain advisory; arbitrary HTML
layouts have no accurate page estimate and need browser print-preview review.

Native exports now use archive v2. Existing v1 archives import without rewriting
captured manifests, documents or hashes. Complete owned definitions, including
source and assets, are pinned in history and retained in backups. Unknown future
types remain portable but require an installed handler to render. No SQL migration
is added. A LaTeX template compiler is not included.

## Verification

Validation covers schemas, API owner/concurrency guards, archive round trips,
legacy history, unsafe markup/resources, bounded binding work and cancellation.
Safety-predicate mutation checks verify the relevant refusals. Browser checks
exercise desktop/mobile authoring, save/copy/Apply and export; downloaded HTML
matches the bytes handed to the print frame. CLI rendering and an isolated
installed editor are checked alongside the complete launcher and package set.
